# g-n-rateur-de-Qrcode-QR-code-generator-
Application web permettant de générer et imprimer des QR Codes pour les pochettes d'archives. À partir d'une catégorie documentaire, l'outil associe automatiquement le libellé et un code , facilitant l'indexation, la numérisation et le classement automatisé des dossiers patients.
